# Shamrock Badminton Club

## Overview

I built this project to practice full-stack web development by creating a website for a badminton club.

The goal was to gain experience building both the frontend and backend of a modern web application, including authentication, database management, API development, and responsive user interfaces.

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM
- PostgreSQL

### Authentication
- JSON Web Tokens (JWT)
- bcrypt

---

## Features

- Responsive club website
- User authentication and authorization
- Secure password hashing
- Database integration with PostgreSQL
- REST API built with Express
- Client-side routing with React Router
- Modern UI styled with Tailwind CSS

---

## What I Learned

This project helped me gain hands-on experience with:

- Building full-stack applications
- Designing and consuming REST APIs
- Authentication and session management
- Database modeling with Prisma
- Connecting React applications to backend services
- Type-safe development using TypeScript
- Project structure and code organization
