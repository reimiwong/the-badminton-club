# Shamrock Badminton Club

## Overview

I built this project to practice full-stack web development by creating a website for a badminton club.

The goal was to gain experience building both the frontend and backend of a modern web application, including authentication, database management, API development, and responsive user interfaces.

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM
- PostgreSQL

### Authentication
- JSON Web Tokens (JWT)
- bcrypt

---

## Features

- Responsive club website
- User authentication and authorization
- Secure password hashing
- Database integration with PostgreSQL
- REST API built with Express
- Client-side routing with React Router
- Modern UI styled with Tailwind CSS

## Environment Variables

Create a `.env` file in the backend project and configure the required variables:

```env
DATABASE_URL=
JWT_SECRET=
```
